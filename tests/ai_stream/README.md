# AI 流式播报隔离测试

需要 Python 3.10+ 和 JDK 11+。从仓库根目录运行：

~~~sh
python tests/ai_stream/run_tests.py
~~~

可使用 --java-home 指定 JDK 目录。测试在本机回环 HTTP 服务上模拟云接口，不访问音箱、HA、MA 或真实 AI 服务，不读取真实配置或密钥。

脚本将固定版本 org.json 20240303 下载到临时目录并校验固定 SHA256。jar 和 class 文件不会写入仓库，运行结束后清理临时目录。

9 项测试覆盖：UTF-8 SSE 碎片、正文与思考隔离、分句顺序/完整回答/一次最终结束、未播失败受控回退、已播失败不重播、新轮次取消、普通 JSON 返回、关闭流式、首正文/首句/整答预算。测试中的 key 为无效的本机测试值。

这些测试验证协议和播报队列，不替代真实音箱的音频、音量或声学测试。

## 播报路由音量测试

~~~sh
python tests/ai_stream/run_route_volume_tests.py
~~~

另有 6 项无需网络的隔离测试，模拟 SPDIF/SPEAKER 切换、音乐静音、其它播报通道不受影响、播报期间显式调音及回切恢复、旧轮次延迟任务丢弃。测试使用假的 AudioManager 验证逻辑；真实设备前/中/后的路由与音量仍需要单独验证。

未听清后续听测试：

    python tests/ai_stream/run_asr_retry_tests.py --java-home "JDK路径"

12项隔离生命周期测试检查真实完成事件门控、一次续听预算、新唤醒/轮次取消、其他播报隔离、错误退出、绝对超时、重复回调与旧清理回调。另16项测试直接提取当前R1文本归一化方法，确认“放点音乐/随机播放点音乐”等保留原意，仅纠正重复播放动词与既有上下首同音短句。该测试不联网、不采集录音、不控制设备；现场提示完成与继续收音仍需在安装后验证。
