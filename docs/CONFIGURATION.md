# 配置说明

## 配置保存在哪里

| 位置 | 保存内容 | 生效方式 |
| --- | --- | --- |
| R1 `/sdcard/r1-local-asr.json` | 网关地址、离线 WS 地址、识别模式、整轮超时、播报引擎、音乐通道 | 下一轮识别/播报 |
| N1 MA 数据下 `r1-cloud-voice/gateway.private.json` | ASR/TTS 接口、密钥、模型、预算、MA 连接 | 大多数设置保存后热更新 |
| 原 R1 `/4` | HA 地址、HA 长期访问令牌 | 按原页面保存 |
| 原 R1 `/5` | 聊天 AI 的接口、密钥、模型与开关 | 按原页面保存 |
| HA 配置 | 点歌规则、实体/区域、MA 令牌、面板、可选电脑控制 | HA 重载/必要时重启 |
| MA 配置 | Apple Music 账户授权、音乐库、播放器协议、队列 | MA 原生设置 |

网页不会把 ASR/TTS 供应商密钥写入 R1 JSON，也不在 URL 中发送密钥。配置读取只返回 `*_configured` 状态。空密钥表示保留，勾选“清除”才删除；新配置校验失败不会覆盖上一份文件。

## ASR

“语音识别模式”有两种：

- **本地快速控制 + 可配置云端 ASR**：音频先经过本地服务断句和识别，默认仅用本地服务断句，全部最终转写交给所选云模型。手动开启“明确短指令优先本地识别”后，完整、明确且足够短的控制句才可采用本地文字。
- **本地离线识别**：R1 直接连接本地识别服务，不调用云端 ASR。开放式问答/歌名的识别能力仍受本地小模型限制。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `asr_base_url` | `https://api.siliconflow.cn/v1` | 服务基础地址；自动追加 `/audio/transcriptions` |
| `asr_model` | `FunAudioLLM/SenseVoiceSmall` | 可直接填写的模型 ID，不限于预设列表 |
| `asr_api_key` | 无公开默认密钥 | ASR 接口 Bearer 密钥；本地免鉴权接口可留空 |
| `asr_timeout_seconds` | 4 秒 | 主模型一次调用总超时，范围 1～30 秒 |
| `asr_fallback_model` | `TeleAI/TeleSpeechASR` | 可选备用模型；空值关闭 |
| `asr_fallback_timeout_seconds` | 4 秒 | 备用模型预算，范围 1～20 秒 |
| `local_first` | false | 完整明确短指令是否优先本地处理 |
| `local_max_chars` | 12 | 本地快捷指令的最大字数；并不取消完整性/纠错检查 |
| `local_asr_url` | `http://127.0.0.1:16066` | 网关访问本地识别的地址 |
| `max_record_seconds` | 18 秒 | 网关允许的最长收音时长，范围 3～30 秒 |

模型 ID 支持字母、数字与 `_ . : / -`，最多 160 字符。这个检查仅判断配置格式，不保证服务商提供该模型。

接口协议为 multipart POST，字段 `model` 和 `file`，文件是 16 kHz、单声道、16 bit PCM WAV；成功响应需含非空 `{"text":"识别文字"}`。只提供聊天/多模态 `/chat/completions` 的服务不能直接填到此处。

当前使用 SenseVoice 4 秒 + TeleSpeech 4 秒备用，并关闭本地文字优先；本地服务仍承担分段，不把其文字用于执行。现场两次 TeleSpeech 空返回后，SenseVoice 正确返回“暂停”和“随机播放点音乐”，因此调整主备次序；这不构成所有远场语音准确率的保证。相同合成问题录音中，GSR 多次直接生成答案而非逐字转写，额外提示词也未纠正，因此不再默认用于纯 ASR。模型仍可手填，服务能力需自行验证；备用调用会增加失败时的总等待。

**整轮识别超时**在 R1 侧设置，默认 45 秒，范围 20～120 秒。网页会检查它是否大于“最长收音 + 主模型预算 + 已启用备用预算 + 3 秒”，避免音箱提前关闭还在工作的识别连接。

开启本地优先时，需要同音修正、含糊或不完整的短句仍须云端复核。空结果或不完整结果不执行控制；播放器中的单独“播放”是完整的恢复播放操作。

R1 侧 `asr_retry_once` 默认 true，8080 可关闭：云端只返回空文字或不完整文字时，在错误提示真正播完后续听一次，无需再次唤醒。每原轮最多一次，提示等待上限 12 秒、续听会话上限 15 秒；新唤醒、其他播报或取消废弃旧续听。网络、服务或配置错误不自动续听；不能按固定延迟猜测提示已经结束。

## 句尾断句和本地声学模型

当前句尾静音是本地 Sherpa 服务的 `--rule2-min-trailing-silence=1.3` 秒，允许句中短暂停顿。此参数不是云端 API 等待时间。

更换离线模型需准备其 ONNX 文件、tokens、相应 `--model-type` 和启动参数；更改断句需编辑 `/etc/init.d/r1-local-asr` 后重启该服务。8080 的模型输入框只选择云端转写模型，不会自动下载本地大模型。实际断句参数请以服务启动参数为准。

## TTS 和音量

“设备自带音色”只读出已有文字，旧识别和问答仍关闭。这不等于保证底层 TTS 完全离线。

云 TTS 可配置以下字段：

| 字段 | 默认值 |
| --- | --- |
| `tts_base_url` | `https://api.siliconflow.cn/v1` |
| `tts_model` | `FunAudioLLM/CosyVoice2-0.5B` |
| `tts_voice` | `FunAudioLLM/CosyVoice2-0.5B:anna` |
| `tts_api_key` | 不公开，独立于 ASR 保存 |
| `tts_timeout_seconds` | 15 秒 |
| `tts_first_chunk_timeout_seconds` | 4 秒 |
| `tts_speed` | 1.0 |
| `tts_gain` | 2.0 |

请求发往 `/audio/speech`，JSON 包含 `model`、`voice`、`input`、`response_format=mp3`、`stream=true`、`speed`、`gain`。服务必须兼容这些字段并返回 MP3；不同供应商的音色名称和扩展参数不一定通用。这个选项不代表已实现 Edge 或所有 TTS 私有协议适配。

TTS 与 ASR 可以使用不同接口和密钥。密钥不会随页面刷新回显；更换配置会清除旧合成缓存。

**音乐音量与助手播报音量分开配置**。部分固件 stream 9 与音乐联动，可在 8080 选择兼容通道 stream 2；当前设备真实回读音乐 4/15、播报 8/15，修改播报后音乐不变。其他设备需回读及听测验证。Snapcast 的高级 r1_hardware_volume_url 可接到 R1 /voice_volume，软件增益保持 unity，直接控制设备音乐音量，避免两层衰减；只对显式配置的播放器生效。

## 音乐、HA 与 AI 分流

- “播放控制直连 MA”：明确的第一首、上下首、暂停、恢复、停止由网关调用 MA；确认播报可以开关。
- “所有音乐指令交给 HA → MA”：使用原有 HA 音乐规则。
- 具体歌名、歌手和风格点歌复用 HA 的搜索脚本，不把“暂停”交给大模型解释。
- 温湿度、电脑控制等明确意图交给 HA。
- 普通问题交给原 AI 配置页的大模型。

“国语精选”目前作为国语流行风格/歌单搜索词，不保证精确匹配用户自己创建的同名歌单。

MA 直连连接字段是 `ma_url`、`ma_queue_id`、`ma_token`。令牌支持原始 token 或带 `Bearer ` 前缀的值。HA 的脚本使用自己的授权文件和队列/提供商 ID，修改网关队列不会自动改写 HA 自动化。

唤醒词、HA 和 AI 的原有配置入口保留。不会为了升级把用户已保存的唤醒词改回“小讯小讯”。

## 网关部署字段

`allowed_clients` 是允许访问网关的客户端 IP 列表，需要保留 `127.0.0.1`，R1 和 N1 地址也必须在内。`r1_control_url` 用于将音乐执行失败反馈给音箱。

`bind_host` / `bind_port` 是网关监听地址，手工修改后需要重启 `/etc/init.d/r1-cloud-voice`；读取接口的 `restart_required` 会提示。它们属于部署配置，不会因为改 ASR 模型而重启服务。

修改 N1 IP 时，同时更新网关监听与允许地址、8080 的网关/离线识别地址、HA 文件中的地址。已有容器、账号、音乐库不需要重建。

## AI 首句播报与等待上限

8080 可配置 ai_streaming（默认 true）、ai_first_content_timeout_ms（4500）、
ai_first_reply_timeout_ms（8000）、ai_answer_timeout_ms（30000）。
界面以秒显示，要求首正文 ≤ 首答 ≤ 整答；不合法配置原子拒绝。
首答预算包括至多一次受控非流式重试；持续返回思考文字不算正文。
首个完整句可播报后即排队，其余句按顺序继续；新唤醒取消旧请求，
过期结果不会再次朗读。关闭流式时也受首答预算约束。

当前 /5 选 Qwen/Qwen3.5-35B-A3B，模型可随时更换。
流式减少等整篇答案的等待，不能保证供应商首段生成速度。
失败会明确提示；不会重新进入旧云知声闲聊通道。
